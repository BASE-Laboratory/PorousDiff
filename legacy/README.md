# Legacy Pre-Conditional Scripts (v0.1 – v0.2)

This directory archives the original single-state unconditional $64^3$ / early prototype scripts (`make_patches64*.py`, `train_diffusion*.py`, `sample_diffusion*.py`, `train_autoencoder.py`, `check_tiffs.py`, `create_volume.py`) from the initial PorousDiff exploratory runs (`Exps 1–8`).

They are preserved for historical reproducibility of `main`, while all current conditional $96^3$ 2-phase and 3-phase multi-electrode workflows live under:
- `scripts/preprocessing/prepare_local_drive_bundle.py`
- `scripts/training/train_carbon_conditional_96.py`
- `scripts/evaluation/sample_carbon_conditional_96.py`
- `scripts/evaluation/evaluate_beamtime_multiplier.py`
- `scripts/evaluation/optimize_clamping_pressure.py`
- `scripts/evaluation/virtual_compress_scan.py`
